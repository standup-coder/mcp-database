# 🌤️ 天气 MCP

> 分类：行业 / 天气
> 适用场景：实时天气查询、多日预报、生活指数、天气提醒
> 数据源：通常对接和风天气、OpenWeatherMap、心知天气等公开 API

---

## 一、简介

天气 MCP 给 LLM 提供了查询天气数据的能力。LLM 不再"胡说天气"，而是真的能告诉你"今天北京有没有雨"、"明天适不适合出门"。
最常见场景：**每日早 8 点给钉钉群推送今日天气 + 通勤建议**。

> 默认工具数：3

---

## 二、核心能力

| 能力 | 说明 |
|------|------|
| 实时天气 | 当前温度、湿度、风力、天气状况 |
| 多日预报 | 未来 3~7 天的天气 |
| 生活指数 | 穿衣 / 紫外线 / 洗车 / 运动指数 |
| 空气质量 | AQI、PM2.5、PM10 |
| 城市搜索 | 城市名 → 城市 ID / 坐标 |

---

## 快速配置

> 直接复制以下片段到 `.env`，再补全你的 Key。完整模板见 [`.env.example`](.env.example)。
>
> 图例：`[REQUIRED]` 必填 · `[STRONG]` 强烈建议 · 其他可选

### 必填

```bash
WEATHER_API_KEY=your_weather_api_key_here  # 和风/OpenWeather 等
```

### 可选

```bash
WEATHER_PROVIDER=qweather  # qweather/openweathermap/xinzhi
WEATHER_DEFAULT_CITY=北京  # 默认城市
WEATHER_UNIT=metric  # metric/imperial/standard
```

## 三、配置

### 3.1 选择数据源

| 数据源 | 免费额度 | 覆盖 | 备注 |
|--------|:-------:|------|------|
| **和风天气** | 1000 次/天 | 中国 + 全球 | 国内最稳定 |
| OpenWeatherMap | 1000 次/天 | 全球 | 国外首选 |
| 心知天气 | 500 次/天 | 中国 | 中文友好 |

### 3.2 环境变量（以和风为例）

```bash
# 必填：API Key
WEATHER_API_KEY=your_weather_api_key_here

# 可选：数据源选择
WEATHER_PROVIDER=qweather          # qweather | openweathermap | xinzhi

# 可选：默认城市（中文或 city id）
WEATHER_DEFAULT_CITY=北京

# 可选：单位
WEATHER_UNIT=metric                # metric | imperial | standard
```

### 3.3 申请 Key

**和风天气**：
1. 打开 <https://dev.qweather.com/>
2. 注册 → 控制台 → 创建应用
3. 选择 "免费订阅" → 复制 Key

**OpenWeatherMap**：
1. 打开 <https://openweathermap.org/api>
2. 注册 → API Keys → 复制默认 Key

## 四、使用示例

### 4.1 查询实时天气

```bash
curl -X POST http://localhost:8000/mcp/execute/weather/current \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"city": "北京"}'
```

返回：

```json
{
  "city": "北京",
  "temperature": "23℃",
  "humidity": "65%",
  "weather": "多云",
  "wind": "东南风 3 级",
  "update_time": "2024-09-15 08:00"
}
```

### 4.2 多日预报

```bash
curl -X POST http://localhost:8000/mcp/execute/weather/forecast \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "city": "上海",
    "days": 7
  }'
```

### 4.3 生活指数

```bash
curl -X POST http://localhost:8000/mcp/execute/weather/lifestyle \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "city": "北京",
    "indices": ["穿衣", "紫外线", "洗车"]
  }'
```

## 六、注意事项

- **API 限流**：免费版通常 1000 次/天，注意别在循环里反复调用
- **城市 ID vs 城市名**：用 city id 更稳，名称有重名（"西安"在多个国家）
- **坐标查询**：精度更高，建议用经纬度（可与高德地图组合）
- **超时**：天气 API 通常很快，`timeout_ms = 5000` 足够

---

## 七、常见组合

- 天气 + 钉钉 = 每日天气播报
- 天气 + 高德地图 = 通勤 + 天气综合提醒
- 天气 + 日历 = 提前提醒户外会议天气
