# 📅 日历 MCP

> 分类：行业 / 日程管理
> 适用场景：日程创建、查询、修改、删除、提醒
> 数据源：Google Calendar、Outlook Calendar、Apple Calendar、企业微信日历、飞书日历

---

## 一、简介

日历 MCP 让 LLM 能直接读 / 写你的日历。最常见场景：
- "看看我明天下午有没有空"
- "帮我建个下周三的会议，主题是技术评审"
- "把 3 点的会改到 4 点"
- "下一个会议开始前 10 分钟提醒我"

> 默认工具数：3

---

## 二、核心能力

| 能力 | 说明 |
|------|------|
| 列出日程 | 时间段内 / 关键字 / 参与人 |
| 创建日程 | 标题、时间、地点、参与人、提醒 |
| 修改日程 | 改时间 / 改地点 / 改标题 |
| 删除日程 | 单条 / 批量 |
| 查询忙闲 | 检查某时间段是否空闲 |
| 今日 / 明日 | 快速获取今日 / 明日全部日程 |

## 快速配置

> 直接复制以下片段到 `.env`，再补全你的 Key。完整模板见 [`.env.example`](.env.example)。
>
> 图例：`[REQUIRED]` 必填 · `[STRONG]` 强烈建议 · 其他可选

### 可选

```bash
CALENDAR_PROVIDER=google  # google/outlook/feishu/wecom/apple
GOOGLE_CREDENTIALS_PATH=./credentials.json  # OAuth 凭据（Google）
GOOGLE_TOKEN_PATH=./token.json  # Token 缓存
CALENDAR_TIMEZONE=Asia/Shanghai  # 时区
CALENDAR_DEFAULT_REMINDER=10  # 默认提醒分钟
```

## 三、配置

### 3.1 选择服务

| 服务 | 认证方式 | 适用 |
|------|---------|------|
| **Google Calendar** | OAuth 2.0 | 海外首选 |
| **Outlook / Microsoft 365** | OAuth 2.0 | 企业首选 |
| **Apple iCloud** | App 专用密码 | macOS / iOS 用户 |
| **飞书日历** | App Token | 字节系企业 |
| **企业微信** | Corp ID + Secret | 腾讯系企业 |

### 3.2 环境变量（以 Google 为例）

```bash
# 必填：OAuth 凭据
CALENDAR_PROVIDER=google          # google | outlook | feishu | wecom | apple
GOOGLE_CREDENTIALS_PATH=./credentials.json
GOOGLE_TOKEN_PATH=./token.json

# 可选：默认日历 ID（一般是 primary）
CALENDAR_DEFAULT_ID=primary

# 可选：时区
CALENDAR_TIMEZONE=Asia/Shanghai

# 可选：默认提醒时间（分钟）
CALENDAR_DEFAULT_REMINDER=10
```

### 3.3 申请 OAuth（Google 流程）

1. 打开 Google Cloud Console：<https://console.cloud.google.com/>
2. 创建项目 → 启用 **Google Calendar API**
3. 配置 OAuth 同意屏幕
4. 创建 OAuth 2.0 客户端 ID（应用类型：桌面应用）
5. 下载凭据 → 重命名为 `credentials.json` → 放到项目根目录
6. 首次运行会弹出授权页，授权后生成 `token.json`

### 3.4 申请飞书 / 企业微信

**飞书**：
1. 飞书开放平台 → 创建企业自建应用
2. 添加"日历"权限
3. 复制 App ID / App Secret

**企业微信**：
1. 企业微信管理后台 → 应用 → 自建应用
2. 开启"打卡 / 日历"权限
3. 复制 CorpID / AgentID / Secret

## 四、使用示例

### 4.1 列出今日日程

```bash
curl -X POST http://localhost:8000/mcp/execute/calendar/list_today \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{}'
```

### 4.2 创建日程

```bash
curl -X POST http://localhost:8000/mcp/execute/calendar/create_event \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "技术评审 - v1.2.3 发布",
    "start": "2024-09-20T14:00:00+08:00",
    "end": "2024-09-20T15:30:00+08:00",
    "location": "会议室 A / Zoom 链接",
    "attendees": ["alice@company.com", "bob@company.com"],
    "reminder_minutes": 10,
    "description": "评审新版本的核心改动"
  }'
```

### 4.3 查询忙闲

```bash
curl -X POST http://localhost:8000/mcp/execute/calendar/check_availability \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "start": "2024-09-20T14:00:00+08:00",
    "end": "2024-09-20T18:00:00+08:00",
    "attendees": ["alice@company.com", "bob@company.com"]
  }'
```

### 4.4 修改 / 删除

```bash
# 修改
curl -X POST http://localhost:8000/mcp/execute/calendar/update_event \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "event_id": "abc123",
    "start": "2024-09-20T16:00:00+08:00",
    "end": "2024-09-20T17:30:00+08:00"
  }'

# 删除
curl -X POST http://localhost:8000/mcp/execute/calendar/delete_event \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"event_id": "abc123"}'
```

## 六、注意事项

- **时区**：跨时区日程务必带上 `+08:00` 这类偏移，不要只发"14:00"
- **OAuth Token 过期**：Google Token 一般 1 小时过期，框架会自动 refresh
- **权限最小化**：OAuth 申请时只勾 Calendar 权限，不要给多余的 scope
- **重复日程**：修改单条用 `event_id`；修改整个系列用 `recurring_event_id` + 修改规则
- **提醒渠道**：默认邮件提醒；要推送钉钉可以另开一个监听服务

---

## 六、常见组合

- 日历 + 钉钉 = 会议开始前自动推送到群
- 日历 + 高德地图 = 自动算会议前的通勤出发时间
- 日历 + 天气 = 提前提醒户外会议天气
