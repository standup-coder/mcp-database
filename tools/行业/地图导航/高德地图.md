# 🗺️ 高德地图 MCP

> 分类：行业 / 地图导航
> 提供方：高德开放平台（lbs.amap.com）
> 适用场景：通勤路线规划、地理编码、逆地理编码、POI 搜索、实时路况

---

## 一、简介

高德地图 MCP 封装了高德开放平台的 Web 服务 API，让 LLM 可以在对话中直接查询路线、距离、时长、地理坐标等信息。最常见的用法是"通勤助手"：每天早上自动查路况 + 估算到达时间 + 推送提醒。

---

## 二、核心能力

| 能力 | 说明 |
|------|------|
| 路线规划 | 驾车 / 步行 / 骑行 / 公交，多种策略 |
| 地理编码 | 地址 → 坐标 |
| 逆地理编码 | 坐标 → 地址 |
| 距离测量 | 两点之间的直线 / 行驶距离 |
| 实时路况 | 路段拥堵情况 |
| POI 搜索 | 关键字搜周边（如"附近的咖啡店"） |

> 默认工具数：4

## 快速配置

> 直接复制以下片段到 `.env`，再补全你的 Key。完整模板见 [`.env.example`](.env.example)。
>
> 图例：`[REQUIRED]` 必填 · `[STRONG]` 强烈建议 · 其他可选

### 必填

```bash
AMAP_API_KEY=your_amap_api_key_here  # Web 服务 API Key
```

### 可选

```bash
AMAP_ORIGIN=116.481485,39.990464  # 出发地坐标
AMAP_DESTINATION=116.481485,39.990464  # 目的地坐标
AMAP_STRATEGY=0  # 0速度/1费用/2距离/3不走高速/4避堵
```

## 三、配置

### 3.1 申请 API Key

1. 打开高德开放平台：<https://lbs.amap.com/>
2. 注册账号 → 进入"应用管理" → "我的应用" → "创建新应用"
3. 添加 Key，**服务平台选择「Web 服务 API」**（不是「Web 端 JS API」）
4. 复制生成的 Key

### 3.2 环境变量

```bash
# 必填
AMAP_API_KEY=your_amap_api_key_here

# 可选：用于默认通勤路线
AMAP_ORIGIN=116.481485,39.990464          # 出发地坐标（经度,纬度）
AMAP_DESTINATION=116.481485,39.990464     # 目的地坐标（经度,纬度）

# 可选：路线策略
# 0 - 速度优先（默认）
# 1 - 费用优先
# 2 - 距离优先
# 3 - 不走高速
# 4 - 避免拥堵
AMAP_STRATEGY=0
```

### 3.3 坐标格式

- 格式：`经度,纬度`（**英文逗号，无空格**）
- 精度：6 位小数即可
- 获取方式：高德地图网页版 → 右键点击位置 → "这里是 X, Y" → 复制

## 四、使用示例

### 4.1 查询通勤路线

```bash
curl -X POST http://localhost:8000/mcp/execute/amap/route_planning \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "origin": "116.481485,39.990464",
    "destination": "116.481499,39.990375",
    "strategy": 0,
    "mode": "driving"
  }'
```

返回示例：

```json
{
  "distance": "15032 米",
  "duration": "32 分钟",
  "tolls": "10 元",
  "traffic_lights": "12 个",
  "steps": [...]
}
```

### 4.2 地理编码（地址 → 坐标）

```bash
curl -X POST http://localhost:8000/mcp/execute/amap/geocode \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"address": "北京市朝阳区国贸"}'
```

### 4.3 周边搜索

```bash
curl -X POST http://localhost:8000/mcp/execute/amap/around_search \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "location": "116.481485,39.990464",
    "keywords": "咖啡店",
    "radius": 1000
  }'
```

## 六、注意事项

- **免费额度**：个人开发者每天 5000 次调用，足够通勤场景
- **Key 类型**：必须是 **Web 服务** Key，不是 JS API Key
- **坐标系**：高德使用 GCJ-02 坐标系（火星坐标），与 GPS 的 WGS-84 有偏移
- **签名**：高德 V5 接口需要 `sig` 签名，框架已自动处理，无需手动加
- **超时**：路线规划建议 `timeout_ms >= 10000`
