# 🧭 Tech Lead MCP 装备清单

> 角色：技术负责人 / Tech Lead / Staff Engineer
> 核心工作：技术选型、架构设计、code review、跨团队协调、团队赋能
> 适用 MCP 数：**25 / 26**（几乎全用，只 1 个不推荐）
> 备注：**5 个重点** + **12 个强推** = 17 个主力工具

---

## 📊 总览

| 优先级 | 数量 | 含义 |
|:------:|:----:|------|
| 🟢 重点必备 | 5 | Tech Lead 每天必用 |
| 🟡 强推 | 12 | 完整技术管理工具链 |
| 🟠 按需 | 8 | 团队/客户特定场景 |
| ⚫ 不推荐 | 1 | Tech Lead 几乎用不到 |
| **合计** | **26** | tools/ 全部 26 个 MCP |

> Tech Lead 是"最杂"的角色 —— 跟 PM 聊需求、跟 SRE 聊稳定、跟 DE 聊数据、跟客户聊方案。
> 所以工具链最全。

## 💡 实战建议

1. **GitHub + Linear + Notion 是你"日常三件套"** — 90% 工作流都从这里出发
2. **Memory 沉淀"团队技术资产"** — 服务/库/owner/SLA/ADR 全部进图谱
3. **Context7 + Docfork 是"调研两件套"** — 选型评审前必须过一遍
4. **Sequential Thinking 用在重大决策时** — 别在 Slack 拍脑袋做架构决策
5. **Figma 看设计稿** — 但别亲自画；让设计师画你评审
6. **Slack / 钉钉 看团队用啥** — 别都开，跨时区沟通反而低效
7. **Database 用来评审 SQL** — 看到 PR 里的慢 SQL 要立刻 push back
8. **E2B 跑 PoC** — 别在生产环境验证新工具
9. **Sentry 关注 P0 趋势** — 每周看一次错误率，不参与日常 oncall
10. **永远不碰"天气"** — 那是给个人助理的
