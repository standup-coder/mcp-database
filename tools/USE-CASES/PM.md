# 📋 PM（产品经理）MCP 装备清单

> 角色：产品经理 / Product Manager
> 核心工作：需求收集、PRD 撰写、竞品调研、进度跟踪、跨团队沟通
> 适用 MCP 数：**18 / 26**（8 个几乎用不到）

---

| 优先级 | 数量 | 含义 |
|:------:|:----:|------|
| 🟢 重点必备 | 5 | PM 日常 80% 时间都在用 |
| 🟡 强推 | 5 | 大部分 PM 都要会 |

## 💡 实战建议

1. **Notion 是你的"产品家"** — 需求池、Roadmap、用户故事、会议纪要都在这里
2. **Linear 不是给你看 Issue 列表的，是让你"管优先级"** — 用 cycle + project 维度组织
3. **Figma 跟 Notion 配合** — Figma 是"设计稿"、Notion 是"文字描述"，双视图对齐
4. **Brave Search 别只用关键词** — 学会用 site: 限定 Reddit/HN/竞品博客
5. **Docfork 在你跟技术评审前用** — 提前查技术栈文档，评审时不再"听不懂"
6. **Memory 沉淀"产品决策日志"** — 砍过的需求、改过的方向都要留痕
7. **Sequential Thinking 用在难决策时** — 砍需求、定价、优先级排序
8. **永远不要碰 Desktop Commander / Filesystem** — 一旦手贱搞错就是大事故
9. **国内客户/团队 = Notion + 钉钉 + 日历**；海外 = Notion + Slack + Google Sheets
10. **别用天气 / Calendar 推产品功能** — 这俩不是给你的
